# Awesome-GIS-For-Local-Government

## Top GIS for Local Government Platforms Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**

*Focused on Municipal Mapping, Spatial Analysis, Public-Sector GIS, Web Maps & Local Government Data*

**Last updated: September 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **GIS in Local Government**. These systems support mapping, spatial analysis, asset inventory, planning, public portals, and operational GIS for cities, counties, and municipal agencies.



**Examples** include ArcGIS Online, Carto, Maptitude, QGIS Cloud, Felt, Mapbox, OpenCities Planner, Cityworks GIS, Nearmap, and Precisely Spectrum (the category leaders).



**Open-source emphasis**: Local government GIS has an exceptionally strong open-source stack. **QGIS**, **PostGIS**, **GeoServer**, **MapLibre**, **Leaflet**, and related projects power production municipal GIS worldwide. This section is heavily expanded.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[ArcGIS Online / ArcGIS Enterprise (Esri)](https://www.esri.com/)**  

  Industry-standard GIS platform widely used by local governments for mapping, analysis, field apps, dashboards, and enterprise spatial data management.



- **[Carto](https://carto.com/)**  

  Cloud-native spatial analytics platform for location intelligence and warehouse-native GIS, used by public-sector and enterprise teams.



- **[Maptitude](https://www.caliper.com/maptitude/)**  

  Desktop and business GIS software often used for demographic, planning, and local government spatial analysis.



- **[QGIS Cloud](https://qgiscloud.com/)**  

  Hosted publishing and web-mapping service for QGIS projects, enabling sharing of open-source desktop GIS work online.



- **[Felt](https://felt.com/)**  

  Collaborative web mapping platform focused on easy map creation and sharing for teams and public engagement.



- **[Mapbox](https://www.mapbox.com/)**  

  Developer-centric mapping platform for custom interactive maps, navigation, and location services used in public-facing applications.



- **[OpenCities Planner (Bentley / similar)](https://www.bentley.com/)**  

  3D city planning and digital-twin style platforms used by municipalities for visualization and planning scenarios.



- **[Cityworks (with GIS integration)](https://www.cityworks.com/)**  

  Public works and asset management platform tightly integrated with GIS for local government operations.



- **[Nearmap](https://www.nearmap.com/)**  

  High-resolution aerial imagery and location data platform used by local governments for planning, assessment, and operations.



- **[Precisely Spectrum / location platforms](https://www.precisely.com/)**  

  Enterprise location and data integrity platforms supporting addressing, geocoding, and spatial data quality for public sector.



## Open-Source GitHub Projects

- **[QGIS](https://github.com/qgis/QGIS)**  

  Leading open-source desktop GIS—full-featured mapping, editing, analysis, cartography, and Python extensibility used extensively by local governments.



- **[PostGIS](https://github.com/postgis/postgis)**  

  Spatial extension for PostgreSQL—the standard open-source spatial database for storing and querying municipal GIS data.



- **[GeoServer](https://github.com/geoserver/geoserver)**  

  Open-source server for publishing geospatial data via OGC services (WMS, WFS, WMTS, WCS) to web maps and applications.



- **[MapLibre GL JS / MapLibre Native](https://github.com/maplibre)**  

  Open-source map rendering libraries (fork of Mapbox GL) for building interactive web and mobile maps without proprietary licensing.



- **[Leaflet](https://github.com/Leaflet/Leaflet)**  

  Lightweight open-source JavaScript library for mobile-friendly interactive maps, widely used for public municipal map viewers.



- **[OpenLayers](https://github.com/openlayers/openlayers)**  

  Feature-rich open-source web mapping library for complex GIS applications and enterprise web GIS.



- **[GDAL/OGR](https://github.com/OSGeo/gdal)**  

  Foundational open-source library for reading, writing, and transforming virtually all geospatial data formats.



- **[GeoNode](https://github.com/GeoNode/geonode)**  

  Open-source geospatial content management system for publishing and sharing spatial data and maps.



- **[MapServer](https://github.com/MapServer/MapServer)**  

  Mature open-source platform for publishing spatial data and interactive mapping applications.



- **[GRASS GIS](https://github.com/OSGeo/grass)**  

  Powerful open-source GIS for advanced geospatial analysis, often used alongside QGIS.



### Additional Strong Open-Source Options

- Building a full municipal stack with **QGIS (desktop) + PostGIS (database) + GeoServer (services) + MapLibre/Leaflet (web)**.

- Using **QGIS Server** to publish projects directly from QGIS.

- Adopting **MapLibre** for public-facing maps when avoiding proprietary map SDK licensing.

- Combining open GIS with open asset management or 311 systems for end-to-end local government operations.

- Accepting that deep local-government data models, survey-grade workflows, and turnkey enterprise support still favor commercial platforms (especially ArcGIS) in many agencies.

- Focusing open-source efforts on data ownership, cost control, and standards-based interoperability (OGC).



**Frameworks for building custom systems**: Store authoritative data in PostGIS → edit and analyze in QGIS → publish via GeoServer or QGIS Server → build public maps with MapLibre or Leaflet → integrate with open or commercial permitting/asset systems. Suitable for cities and counties with GIS capacity. Many local governments run hybrid environments (open core + commercial components).
